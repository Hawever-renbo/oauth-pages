土族阿吾 (Tu Awu)

Personal AI assistant — single-user private deployment
个人 AI 助理 — 单人自用部署

About this application / 应用说明

土族阿吾 is a privately deployed personal assistant that runs on the account owner's own computer. It connects to the owner's Google account only to read and manage the owner's own calendar events and tasks, and to read the owner's own email, so that the assistant can help with scheduling, reminders and follow-ups.

本应用是部署在账号所有者本人电脑上的私人助理程序，仅连接所有者本人的 Google 账号，用于读取和管理其本人日历、任务与邮件，实现日程安排、提醒与跟进。

There is no multi-user sign-up: only the account owner uses this application. 本应用不面向公众注册，仅供账号所有者本人使用。

Services accessed / 访问的 Google 服务

  • Google Calendar — read and create the owner's own events and reminders
    读取与创建本人日历事件与提醒
  • Google Tasks — read and manage the owner's own task lists
    读取与管理本人任务清单
  • Gmail — read the owner's own messages to detect actionable items
    读取本人邮件以识别待办事项

Data is processed locally on the owner's machine. It is never sold, shared or transferred to any third party, and is not used for advertising.

数据仅在所有者本机处理，不出售、不共享、不转让给任何第三方，也不用于广告。
