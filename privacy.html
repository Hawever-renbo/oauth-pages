隐私政策

Privacy Policy — 土族阿吾 (Tu Awu)  |  Last updated 2026-10-05

1. 概述 / Overview

土族阿吾（以下称“本应用”）是部署在账号所有者本人设备上的私人助理程序。本应用 仅服务于唯一账号所有者（single user），不提供公开注册，也不收集非用户的个人数据。

Tu Awu ("the Application") is a privately deployed personal assistant running on the account owner's own device. It serves a single user only, offers no public sign-up, and does not collect personal data from anyone other than its owner.

2. 我们访问的数据 / Data we access

经账号所有者明确授权，本应用通过 Google OAuth 访问以下数据：

  • Google Calendar — 读取与创建所有者本人的日历事件、提醒
  • Google Tasks — 读取与管理所有者本人的任务清单
  • Gmail — 读取所有者本人邮箱中的邮件，用于识别待办事项与截止日期
  • 基本账号信息 — 邮箱地址与用户 ID，用于区分账号

With the owner's explicit consent, the Application accesses, via Google OAuth: the owner's own Google Calendar events, their own Google Tasks, their own Gmail messages, and basic account identifiers (email address, user ID).

3. 数据如何使用 / How data is used

  • 仅在所有者本机（及所有者自己配置的私密远程运行环境）处理；
  • 仅用于：日程创建与提醒、任务跟进、从邮件中提取待办信息；
  • 不用于广告、画像、营销或任何形式的自动化决策；
  • 不用于训练机器学习模型。

Data is processed solely on the owner's own machine (and the private runtime the owner configures). It is used only for scheduling, reminders, task follow-up and extracting action items from the owner's own mail. It is never used for advertising, profiling, marketing, model training or automated decision-making.

4. 数据共享 / Data sharing

本应用不出售、不出租、不共享、不转让任何 Google 用户数据给任何第三方。 除为完成上述功能而调用 Google 官方 API 外，不存在任何对外数据传输。

Google user data is never sold, rented, shared or transferred to any third party. The only outbound data flow is to Google's own APIs, strictly to perform the functions described above.

5. 数据存储与安全 / Storage and security

  • OAuth 刷新令牌与凭据仅保存在所有者本机的加密密钥链（macOS Keychain）中，文件权限 600；
  • 不设云端数据库，不保留超出功能所需的副本；
  • 本应用开发者（即所有者本人）不以任何形式集中存储用户数据。

OAuth refresh tokens are stored only in the owner's local encrypted keychain (macOS Keychain) with owner-only file permissions. No cloud database is used and no copies are retained beyond what the functions require.

6. 数据保留与删除 / Retention and deletion

所有者可随时在 Google 账号的 第三方应用权限页面 撤销本应用的访问权，撤销后本应用将立即失去全部数据访问能力，本机留存的授权令牌 同时失效。如需删除本机已留存的任何数据副本，请联系下方邮箱，我们将在 7 个工作日内 完成删除。

You may revoke the Application's access at any time at myaccount.google.com/permissions. On revocation the Application immediately loses all access and its locally stored tokens become invalid. To request deletion of any locally retained copy, email us below; deletion is completed within 7 business days.

7. 有限使用声明 / Limited Use disclosure

本应用对 Google API 所获信息的使用与传输遵守 Google API Services User Data Policy， 包括其「有限使用（Limited Use）」要求。

The Application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. 儿童 / Children

本应用不面向儿童，也不会有意收集儿童的个人数据。
The Application is not directed to children and does not knowingly collect data from children.

Any update will be reflected by the "Last updated" date at the top of this page.
